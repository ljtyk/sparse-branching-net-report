# Self-Organizing Sparse Branching Nets — report

A standalone write-up of a toy-scale investigation into whether Mixture-of-Experts
routing self-organizes into useful modular structure: modular arithmetic, a
byte/token language model, a nine-experiment study of per-token expert switching,
and a shared expert pool with adaptive depth.

**Read it: https://ljtyk.github.io/sparse-branching-net-report/**

The page is a single self-contained `index.html`. Verdict, in short: a careful
characterization study with clean negative results and one small positive one,
not a breakthrough. The code and full working reports live in a separate private
repository.
